# ROMANTIC16 WeChat Mini Program

A native Chinese-language Mini Program sharing the website's questionnaire logic, 16 illustrated literary profiles, visual design, and result posters.

## Open the project

1. Install and sign in to the official WeChat DevTools.
2. Import `romantic16-miniprogram/`, not its `miniprogram/` child directory.
3. Supply your own Mini Program AppID. The committed configuration intentionally leaves it empty. A DevTools test account may be suitable for evaluation; publication and account-dependent device capabilities require your own account.
4. Use a stable DevTools release and base library 3.8.2 or a compatible newer version, then compile. No runtime dependencies, npm build, or server configuration are needed.

## Features

- 15 behavioral style questions, 8 most-like/least-like scenarios, and 2–4 adaptive follow-ups. The product does not offer skipping.
- Answer revision, restart, local progress recovery, and explicit record deletion.
- Focused, dual, distributed, and insufficient-evidence results, with illustrations and non-diagnostic explanations.
- Locally generated 1080 × 1800 PNG posters using native Canvas 2D. Portraits, fonts, question data, and the QR image are bundled.
- Image sharing through `wx.showShareImageMenu`; the user selects a recipient and confirms sharing.
- Album saving through `wx.saveImageToPhotosAlbum`; success is displayed only after the native write succeeds. Initial use requires privacy consent and album write permission.
- Permission refusal, settings recovery, sharing cancellation, unsupported clients, generation failures, and retry handling.

## QR destination and sharing

The poster QR points to the existing public questionnaire:

[romantic16.netlify.app](https://romantic16.netlify.app/)

The invitation action shares a Mini Program home-page card without personal answers or results. After publishing the Mini Program, replacing the website QR requires an authentic Mini Program code generated by that account.

Image sharing does not attach a Mini Program entrance. WeChat may restrict Moments sharing of images containing ordinary QR codes; this implementation integrates friend image sharing and does not claim unrestricted Moments support.

## Account preparation and publication

The account owner must supply an AppID and complete the applicable account information, service category, filing, and review requirements in the WeChat console. Configure the console's user privacy protection declaration to accurately describe album write access for saving posters.

Import, preview, and upload can be performed in DevTools under the owner's login; no AppSecret needs to be sent to a developer. Test a complete questionnaire, poster generation, recipient selection, album saving, permission refusal, and permission recovery on both iPhone and Android.

Uploading in DevTools is followed by console review and publication. Project files, local tests, and a preview release do not establish production publication.

## Privacy and interpretation

The application does not require login, collect WeChat avatars or nicknames, request contacts, read the photo album, upload answer records, or integrate an analytics SDK. Local storage supports progress recovery and can be cleared on the home page.

Sharing is voluntary; a shared image contains its displayed literary result. Posters are temporary WeChat files and are written to the album only after the user requests saving and grants permission.

Results are uncalibrated literary archetype explorations, not diagnoses, personality probabilities, or screening tools.

## Checks and maintenance

```sh
npm test
```

Checks use only Node.js built-in modules; no `npm install` is needed. They cover scoring/content parity, answer state, local recovery, native API parameters, and error handling with mocked WeChat APIs. They cannot replace compilation and real-device permission/share checks under an actual account.

`scripts/sync-data.mjs` synchronizes the question bank, profiles, reference scoring engine, and poster drawing layout from the adjacent `romantic16-site/dist/`. It adapts module formats mechanically. Regeneration uses macOS `sips` to compress existing illustrations; ordinary project import does not require running it. Bundled fonts include OFL notices.

```sh
npm run sync
npm run package
```

Packaging runs the checks, verifies that the main bundle is below 2 MiB, and creates an import ZIP under the ignored `artifacts/` directory. Image compression changes file size rather than questionnaire content or scoring.

No AppID is configured in this repository, and local verification does not confirm account setup, DevTools compilation, device testing, review, or publication.
